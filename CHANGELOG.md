# Changelog

Each version's section is sent to Firefox Add-ons as its release notes, so
write it for the people who use the add-on. To release, bump `version` in
`manifest.json`, add its section here, and push to `main`.

## 0.8.1

First public release: tracking hits from 57 tools with decoded events, IDs, parameters and consent state; GTM dataLayer events and snapshots; click to copy any ID or table cell.
